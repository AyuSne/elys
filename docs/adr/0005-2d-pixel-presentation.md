# 表现层由 3D 低模切到 2D 像素

#9 把演示从体块换成了 Quaternius 低模：模型、树、房子都到位，但画面依然"假"。原因不是挑错了包，而是这一类通用 CC0 低模的结构：全部纯色无贴图，所以地面只能是一整块 38×28 的单色方片；场景没有地形起伏，光打上去亮度完全均匀；天空用的是 Unity 默认渐变，地面边缘直接露出来。三处叠起来，观感停在"学生作品"——这是素材来源决定的天花板，修细节修不上去。

选择整套表现层改成 2D 像素瓦片（素材取自星露谷物语的一手图集）：16px 的瓦片、手绘的建筑与角色、成套的 UI 框，同一块画面立刻读成"游戏"。代价是丢掉 #9 刚做完的第三人称 3D 跟拍（降级为"跟随 + 推近"），以及四个表现层测试 fixture 作废。域层与 132 条断言不受影响——它们只打在 `FarmWorld` 与 `IModelClient` 两条缝上。

**考虑过的选项**：

1. 换一套付费风格化 3D 包（POLYGON Farm $49.99 / Stylized Fantasy Farm $55）并重做地形、天空与光照。否决原因：钱不是问题，问题是那三样（地形、天空、露边）**换任何包都得自己做**，而做完之后仍是我们自己摆位的通用模块；等于花 3–4 天买一个"更精致的学生作品"。
2. 保留 3D，只修地面贴图、天空盒、雾与光照（约 3 小时）。否决原因：这是判断 3D 天花板用的实验，不是终点；用户的目标是"看起来不假"，而这个实验最多把它推到"能看"。
3. 两套表现层并存，HUD 加开关切换。否决原因：两套表现层要各自维护相机、输入与 HUD 布局，成本翻倍，而且切换会让人以为在玩两个游戏。

**后果**：表现层的运行时依赖从 FBX + 材质转换变成"贴图 + 切图"，`QuaterniusArt`、`UrpMaterialConverter`、`ModelPlacement` 逐步退出；`Assets/Resources` 里的 3D 素材挪出打包目录，避免 98 MB 的包里再背一套没人用的模型。素材本身是原作游戏图集，仓库保持私有、只做演示用途——这一点写进 spec 的交付约束，不随代码扩散。3D 版本留在 `main`，2D 在单独分支上做，合入之前随时可回退。
